# Stage Rush #

##Descripción
Stage Rush es un videojuego desarrollado en Unity como proyecto final del CFGS en Desarrollo de aplicaciones Multiplataforma(DAM)

## Características
La principal mecánica del juego consiste en completar dos tramos, de punto A a punto B, siguiendo indicaciones de las curvas del trazado.

El jugador se encargará de manejar el vehículo y seguir las indicaciones, tratando de hacerlo en el menor tiempo posible, para ello, se usa un sistema contrarreloj, además de validación mediante puntos de control, aplicando las sanciones correspondientes según la infracción cometida.

Una vez el jugador finalice el trazado y ha iniciado sesión, podrá ver su tiempo final, además de poder acceder a una tabla de tiempos global y ver el tiempo final del resto de jugadores y compararse a ellos, fomentando la competición.
